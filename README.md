# 网页托管

用于通过 GitHub Pages 托管独立网页与在线练习工具。

## 当前网页

[打开理论问题题库](https://whxcjm.github.io/web-pages/)

题库包含100道复习题：党章党史基础40题、创新理论30题、近期时政30题。资料核查日期为2026年11月2日，42题标为优先掌握。

支持手机阅读、搜索筛选、遮住答案自测、标记待复习或已掌握，以及每组一道理论基础题和一道时政题的模拟练习。掌握状态保存在当前浏览器本地，手机与电脑分别记录。

## 更新网页

首页文件是 `index.html`，题目和样式均已内嵌。更新该文件并提交到 `main` 分支后，GitHub Pages 会自动发布。

其他网页可放在独立子文件夹中，例如 `example/index.html`，对应访问路径为 `/web-pages/example/`。

`.nojekyll` 用于直接发布静态文件。本仓库只保存网页内容。
